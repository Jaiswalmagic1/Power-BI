# 📊 Blinkit Sales Performance Dashboard

A Power BI dashboard project designed to analyze sales performance data for **Blinkit – India's Last Minute App**.

![image](https://github.com/user-attachments/assets/97ba1129-7e16-435c-ae82-a6dac5742272)


---

## 🔧 Tools & Technologies Used

- **Power BI** – Data visualization and dashboard development  
- **DAX** – Created custom measures and KPIs  
- **Excel** – Source data  
- **Business Requirement Document (BRD)** – [View BRD](#) *(Update this with your actual link)*

---

## 📂 Project Workflow

1. **Data Loading**: Imported data from Excel into Power BI.
2. **Data Cleaning**: Handled missing values, filtered columns, formatted dates, and standardized categories.
3. **Data Modeling**: Built relationships and parameters to support report interactivity.
4. **DAX Measures**:
   - Total Sales  
   - Average Sales  
   - Number of Items  
   - Average Rating

## 📈 Dashboard Highlights

### 🔍 Filters Panel (Left Sidebar)
- Outlet Location Type  
- Outlet Size  
- Item Type  
- Navigation buttons:
  - 🏠 Home  
  - 🔄 Reset  
  - 📅 Calendar View  
  - ℹ️ Info  

### 📊 Key Performance Indicators (KPIs)
- 💰 **Total Sales**: `$1.20M`  
- 📦 **Number of Items**: `8523`  
- 💵 **Average Sales**: `$141`  
- ⭐ **Average Rating**: `3.9`

### 📊 Visual Insights
- Sales by:
  - Fat Content (Low Fat vs Regular)
  - Item Type (Fruits, Snacks, Household, etc.)
  - Outlet Tier (Tier 1, 2, 3)
- Outlet Establishment Trend (2012–2022)
- Sales comparison by Outlet Size and Type
- Matrix comparison: Sales, Ratings, Visibility across Supermarket types

---

## 🎯 Objective

The dashboard enables stakeholders to:

- Understand trends in product sales across locations and outlet types
- Compare item category performance and ratings
- Analyze historical outlet growth and potential market opportunities
- Support data-driven decisions with visual and interactive insights
